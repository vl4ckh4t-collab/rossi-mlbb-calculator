# ROSSI MLBB Calculator 🌸

Burmese + English bilingual MLBB Diamond price/profit calculator with Sakura, Ocean Blue, Mint and Dark themes. Built with static HTML, CSS and JavaScript for free GitHub Pages hosting.

## Files
- `index.html` — page content and ROSSI branding
- `style.css` — responsive design and theme colors
- `script.js` — profit calculator, editable Diamond plans, theme preference

## Publish on GitHub Pages
1. Sign in at https://github.com and create a **Public** repository named `rossi-mlbb-calculator`.
2. Click **Add file → Upload files** and upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder (upload the files themselves, not the containing folder).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/(root)`, then click **Save**.
6. After deployment, the site URL will look like `https://YOUR-USERNAME.github.io/rossi-mlbb-calculator/`.

## Notes
- Initial Diamond plan costs are illustrative examples. Replace them with your real purchase costs.
- Profit calculation: selling price = cost price × (1 + profit percentage / 100).
- This is a calculator only. It does not connect to Smile.one, fetch live prices, process payments, or top up Diamonds.
- No API key or secret should be placed in a public GitHub Pages repository.
